# PanicHelper / АнтиПаника

Простое Android-приложение для дневника самочувствия, приступов тревоги, давления и пульса.

## Важно

Приложение не заменяет врача и не ставит диагноз.

При боли в груди, обмороке, сильной одышке, нарушении речи, асимметрии лица или резкой слабости нужно вызывать скорую помощь.

## Возможности

- дневник давления, пульса и тревоги;
- запись приступов;
- отметка триггеров;
- дыхательное упражнение;
- техника заземления;
- графики и сводка;
- кнопка звонка 112/103;
- локальное хранение данных без интернета.

## Сборка

Требования:

- JDK 17;
- Android Studio;
- Android SDK 34.
